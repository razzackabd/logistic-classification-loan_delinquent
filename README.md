# logistic-classification-loan_delinquent
Loan Delinquency Prediction Using Logistic Regression

📖 Project Description

This project focuses on predicting loan delinquency using Logistic Regression, a widely used statistical and machine learning algorithm for binary classification problems.
The model estimates the probability of a borrower becoming delinquent based on financial, credit, and demographic features.

Logistic Regression is interpretable and helps understand how each feature influences loan default risk.

🎯 Objectives

Predict loan delinquency status (Delinquent / Non-Delinquent)

Apply Logistic Regression for classification

Interpret feature coefficients for risk analysis

Support data-driven credit decision making

🛠️ Technologies Used

Python

Pandas, NumPy – Data preprocessing

Matplotlib, Seaborn – Data visualization

Scikit-learn – Logistic Regression implementation

📊 Dataset

Dataset: Loan Delinquent Dataset

Features include:

Loan amount

Applicant income

Credit history

Employment details

Loan status

⚙️ Methodology

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Feature encoding and scaling

Train-test split

Model training using Logistic Regression

Model evaluation and interpretation

📈 Evaluation Metrics

Accuracy

Precision

Recall

F1-Score

ROC-AUC

Confusion Matrix

✅ Results

The Logistic Regression model provided reliable baseline performance and clear interpretability, helping identify key factors influencing loan delinquency.

🚀 Conclusion

This project demonstrates how Logistic Regression can be effectively used for loan default prediction, offering both predictive power and model transparency for financial risk assessment.
